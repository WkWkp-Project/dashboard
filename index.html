Name / Recipient Role Token Scope (Campaigns) Expires Actions
How access works

Internal (Wakuwaku ทีม): login ผ่าน Google Workspace → เห็นทุกแคมเปญ, แก้ไขได้

Client (ลูกค้า): ใช้ Quick Handoff Viewer + Access Token → เห็นเฉพาะแคมเปญที่ token ครอบคลุม, อ่านอย่างเดียว

หลังหมดสัญญา: generate token แบบ permanent ให้ลูกค้า แล้วส่ง bundle ZIP ที่มี token ฝังไว้ — ลูกค้าเปิดใช้งานได้ตลอดโดยไม่ต้อง login

1:1 Sharing: 1 token = 1 lookup scope. ถ้ามีลูกค้าหลายคน, generate token แยกกัน. Token สามารถ revoke ได้ทุกเมื่อ
